# Slotted ALOHA 시뮬레이터 설계

## 경쟁 영역

LB와 Alert는 각각 독립된 경쟁 영역을 갖는다. 열은 시간 슬롯이며, 행은 주파수 채널이다. 화면에서는 Alert를 위에, LB를 아래에 배치한다. 주파수 축의 직선은 영역 이름 열과 슬롯 영역 사이에 위치한다. 축에는 ‘주파수’와 ‘시간’을 표시한다.

각 영역 안에서 맨 아래 줄이 주파수 위치 1(가장 낮은 주파수)이고, 위로 갈수록 주파수가 높다. 왼쪽 끝이 시간 1이다. 주파수 축 옆에 주파수 위치 번호를 표시한다(줄이 너무 낮으면 1과 5의 배수만 표시). 슬롯 번호는 주파수 위치 1의 시간 1부터 시간 방향으로 센 뒤 다음 주파수 위치로 올라간다. 마지막 주파수 위치가 다 차지 않으면 맨 위 줄이 일부만 채워진다.

단말 수는 실제 경쟁에 참여하는 단말의 수다. 두 영역에 모두 참여하는 단말이 3대이면 같은 단말 3대가 LB에서 경쟁하고, Alert에서도 3대가 경쟁한다.

한 번의 전송은 해당 영역에서 시간 슬롯 하나와 주파수 채널 하나를 점유한다. 각 칸의 전송 시도 수가 0이면 유휴, 1이면 성공, 2 이상이면 충돌로 판정한다. 충돌한 칸의 전송은 모두 실패로 집계한다.

## 입력 파라미터

| 파라미터 | 값 또는 의미 |
| --- | --- |
| 심볼레이트 | 500, 2000, 4000 sps 중 하나 |
| Wave ID | 3, 13 중 하나 |
| LB 채널 수 | LB 영역에서 경쟁할 수 있는 전체 칸 수 |
| Alert 채널 수 | Alert 영역에서 경쟁할 수 있는 전체 칸 수 |
| 단말 수 | 실제로 경쟁에 참여하는 단말 수 |
| 슈퍼프레임 주기 | 모든 단말이 동시에 경쟁하는 접속 주기 |
| 시뮬레이션 시간 | 시뮬레이션의 전체 경과 시간 |
| 그룹 수 | Alert와 LB가 공유하는 그룹(영역) 수. 0이면 그룹을 쓰지 않는다 |
| 반복 횟수 | 같은 설정을 실행마다 다른 시드로 반복할 횟수(1~10,000). 1이면 한 번만 실행한다 |

## 시간 슬롯 수와 영역 크기

심볼레이트와 Wave ID 조합이 영역별 격자의 시간 슬롯 수를 정한다. 초안에서는 해당 조합의 최대 슬롯 수만큼 열을 사용한다.

| 심볼레이트 | Wave ID 3 | Wave ID 13 |
| ---: | ---: | ---: |
| 500 sps | 9 | 3 |
| 2000 sps | 36 | 12 |
| 4000 sps | 72 | 24 |

- 영역의 사용 가능 칸 수는 입력한 채널 수와 같다.
- 주파수 행 수는 `채널 수 ÷ 시간 슬롯 수`를 올림해 계산한다.
- 각 행은 슬롯 번호 순서로 채운다. 나머지가 있으면 마지막 행에 나머지 개수만큼 경쟁 가능 칸을 배치한다.

4000 sps와 Wave ID 3의 시간축은 72열이다. LB 채널 수가 360이면 5행 360칸이다. 361이면 6행을 배치하고 마지막 행의 첫 칸까지 사용한다.

## 슈퍼프레임 주기와 수신 결과

모든 단말은 같은 슈퍼프레임 주기로 경쟁한다. 각 단말은 참여하는 영역의 경쟁 가능 칸 중 하나를 같은 확률로 선택한다.

수신기는 슈퍼프레임이 끝날 때마다 해당 회차의 성공과 충돌을 집계한다. 첫 집계는 한 주기가 지난 시점이며, 시뮬레이션 종료 시각까지 완료된 회차를 집계한다. 주기가 1초이고 시뮬레이션 시간이 5초이면 수신 집계 시각은 1, 2, 3, 4, 5초다.

## 최종 집계와 내보내기

활성 영역마다 단말별 전송 성공 여부를 회차에 걸쳐 기록한다. 최종 접속 실패 단말 갯수는 그 영역에 시도한 단말 중 종료 시점까지 성공이 0번인 단말 수다. 화면과 저장 파일은 Alert와 LB만 표시한다. 설정 값과 최종 접속 실패 단말 갯수는 위쪽, 선택 회차의 전송 통계는 아래쪽 표로 표시한다.

결과 탭의 설정 값은 표 대신 카드 형태로 표시한다. 위쪽 세 줄은 공통 설정(심볼레이트·Wave ID·시간 슬롯 / 슈퍼프레임 주기·시뮬레이션 시간·수신 회차 / 단말 수·그룹 수)이고, 구분선 아래는 채널 타입별 표(채널 수, 주파수 위치 수, 그룹을 쓴 실행이면 단말 배정·슬롯 배정 방식)다.

하단 표의 성공 건수, 충돌 칸 수, 유휴 칸 수는 선택 회차의 값이다. 누적 성공 건수와 누적 충돌 전송 건수는 모두 1회차부터 선택 회차까지 합산한다. 회차 이동 작업에서 누적 값을 다시 계산하고, 화면은 완료된 작업의 값만 표시한다. 최종 접속 실패 단말 집계는 회차 이동과 관계없이 유지한다.

전송 추이는 영역을 선택해 수신 시각별 성공 전송 단말 수와 충돌 전송 단말 수를 한 그래프에 표시한다. 표시하는 모든 지점에 값과 표식을 붙인다. 숫자가 겹치지 않도록 화면에는 선택 회차에 맞춘 연속 구간을 표시하며 회차 이동으로 범위를 바꾼다.

내보내기는 테두리와 차트를 지원하는 XLSX 한 파일로 제공한다. `결과` 시트에는 상단 설정·실패 단말 표, 두 영역의 Excel 꺾은선 그래프, 하단 Alert·LB 최종 누적 결과 표가 있다. `회차별 데이터` 시트에는 모든 회차의 데이터와 회차별 누적 값이 있다. 차트는 해당 데이터 셀을 참조하고 각 지점의 값을 표시한다. 계열 이름(성공 건수, 충돌 전송 건수 등)은 `결과` 시트의 숨긴 Z열 셀을 참조하고 같은 값을 캐시로 저장한다. 이렇게 하면 Excel이 아닌 프로그램에서도 범례가 ‘계열 1’ 대신 실제 이름으로 보인다. 내보내기는 화면의 선택 회차와 관계없이 모든 결과를 포함한다.

Open XML 패키지를 C에서 직접 기록하므로 Excel 설치나 추가 DLL이 필요 없다. 임시 파일을 완성한 뒤 목적지 파일을 교체한다. 실패하거나 중지하면 임시 파일을 제거하고 기존 결과를 보존한다. Excel 행 수를 초과하는 결과는 잘라 저장하지 않고 제한을 안내한다.

구현에는 C 코딩 규칙을 적용한다. [C 코딩 규칙](CODING_RULES.md)

## 반복 실행 평균

1.4.0.0에서 추가했다. 한 번의 실행은 난수에 따라 결과가 크게 흔들린다(단말 300대·Alert 144칸·12회차에서 최종 접속 실패 단말 수의 표준편차 약 6.5대). 그룹 적용과 미적용의 차이를 판단하려면 여러 번 실행한 평균이 필요하다.

- 반복 1은 화면의 상세 결과(격자, 전송 추이, 회차 이동, 회차별 표, Excel 회차 시트)를 만드는 실행이며 기존 시드를 그대로 쓴다.
- 반복 k(k ≥ 2)는 실행 시드에서 만든 별도 시드(`GetRepeatSeed`)로 같은 설정을 처음부터 다시 계산하고, 최종 값(누적 성공·누적 충돌 전송·충돌 칸·유휴 칸, 최종 접속 실패 단말 수, 그룹을 쓴 실행이면 같은 시드의 그룹 미적용 값)만 보관한다. 각 반복은 같은 시드로 전체 실행한 결과와 정확히 같다.
- 반복이 끝나면 반복 1의 마지막 회차를 다시 계산해 격자와 회차 표가 반복 1을 보이게 한다. 중지하면 기존처럼 결과를 버린다.
- 통계는 평균, 표본 표준편차(n−1), 최소, 최대다. 차이는 반복마다 `그룹 적용 − 그룹 미적용`을 계산한 뒤 통계를 낸다.
- 화면: 설정 값 카드에 반복 횟수, 최종 접속 실패 단말 갯수 표에 `평균 ± 표준편차`(제목에 `n회 평균`), 하단 표 선택에 `반복 통계`(반복 실행 후 기본 선택). 나머지 표의 제목에는 `1번째 실행`을 붙인다.
- Excel: 마지막 시트 `반복 실행`에 통계 표와 반복별 결과(실행 번호, 시드, 채널 타입별 값)를 둔다. `결과` 시트 안내 문장에 반복 1의 결과임을 적는다.
- 그룹 미적용과 비교한 시뮬레이션 평균은 닫힌식 `n × (1 − (1 − 1/s)^(n−1))^R`(n = 그룹 단말 수, s = 그룹 칸 수, R = 회차 수)과 일치한다. 칸당 단말 수가 같으면 그룹을 나눠도 평균 실패 수는 거의 같고, 칸 수가 정수로 나뉘며 생기는 불균형이나 단말 수 불균형이 있으면 늘어난다.

## 그룹별 슬롯 배정

1.2.0.0에서 구현하고 1.3.0.0에서 사용성을 개선했다(특정 그룹 단말 수 변경 시 나머지 자동 맞춤, 그룹 설정 창 정리, 그룹 합계 행, 표 높이 조절). 사용자 표현의 ‘영역’과 ‘그룹’은 같은 뜻이다. 화면과 파일에서는 Alert·LB를 가리키는 기존 ‘영역’ 표기와 구분하기 위해 ‘그룹’으로 표시한다. 그룹 설정 창에서는 Alert·LB를 ‘채널 타입’이라고 부른다.

### 소스 구성

| 소스 | 역할 |
| --- | --- |
| `Group.c`, `.h` | 그룹 설정(자동 균등/직접 지정), 현재 격자로의 좌표 복원, 검사와 오류 문구, 실행용 배정표(`AreaGroupPlan_t`) 생성, 칸 편집 |
| `Simulation.c`, `.h` | 그룹별 칸 선택과 집계, `SimulateAllRounds`(그룹 실행 + 같은 시드 미적용 비교), 그룹·미적용 누적 계산 |
| `GroupDialog.c`, `.h` | 그룹 설정 모달 창, 격자 클릭·드래그·범위 편집, 적용 전 검사 |
| `Chart.c`, `.h` | 그룹 색 보기, 선택 그룹 강조, 편집 드래그, 그룹 전송 추이, 그룹별 작은 그래프 |
| `Report.c`, `ReportXml.h` | 동적 ZIP 항목, 그룹 시트·차트, 크기 사전 검사 |

설정 데이터는 영역마다 `그룹별 단말 수 고정 여부와 고정 값 + 슬롯 직접 지정 여부 + 칸별 소유 그룹(배정 당시 시간 슬롯 수와 함께)`로 보관한다. 실행할 때 현재 파라미터 기준으로 풀어서 그룹별 단말 구간 끝, 허용 칸 목록, 칸별 그룹을 만든다. 실행 결과는 이 배정표를 보관하므로 이후 입력 편집이 결과를 바꾸지 않는다.

### 확정한 조건

- 시뮬레이션 탭은 하나만 둔다. `그룹 수`가 0이면 기존 방식(모든 단말이 영역의 모든 칸에서 경쟁)으로 실행하고, 화면과 Excel 파일도 기존과 같다.
- 그룹 수는 Alert와 LB가 공유한다. 그룹 수가 3이면 Alert와 LB 모두 그룹 1·2·3을 갖는다. 입력 범위는 0~100이다.
- 그룹에 속하는 단말은 그룹별 단말 수로 정한다. 그룹 순서대로 단말 ID를 연속 배정한다. 단말 100대에 그룹 1이 10대이면 그룹 1은 단말 1~10번이다.
- 그룹별 단말 수는 Alert와 LB에서 따로 정할 수 있다. 같은 단말이 Alert에서는 그룹 1, LB에서는 그룹 2에 속할 수 있다.
- 단말 수가 0인 그룹은 어떤 단말도 접속하지 않는다. 그 그룹에 배정된 칸은 항상 유휴다.
- 같은 영역의 한 칸은 한 그룹에만 배정한다. Alert와 LB의 같은 좌표는 서로 다른 칸이다.
- 기본값은 단말 균등 분배와 슬롯 균등 배정이다. 설정 창에서 직접 바꿀 수 있고, `단말 균등 분배`·`슬롯 균등 배정` 버튼으로 언제든 균등 상태로 되돌린다.
- 그룹을 쓴 실행은 같은 시드로 그룹 미적용 결과도 함께 계산해 차이를 화면과 Excel에서 비교한다.

### 배분과 검사 규칙

- 단말 수는 그룹마다 `직접`(고정) 또는 `자동`이다. 처음에는 모든 그룹이 자동이다.
  - 자동 그룹은 `N − 직접 그룹 단말 수 합계`를 나눠 갖는다. 몫을 나누고 나머지는 앞 자동 그룹부터 한 대씩 더한다. 모두 자동이면 기존 단말 균등 분배와 같다.
  - 한 그룹의 단말 수를 바꾸면 그 그룹만 직접이 되고 나머지 자동 그룹이 합계를 맞추므로, 특정 그룹만 바꿔도 단말 수 합계 오류가 나지 않는다.
  - 값을 비우고 변경하면 그 그룹은 자동으로 돌아가고, `단말 균등 분배`는 모든 그룹을 자동으로 되돌린다.
- 슬롯 균등 배정: 슬롯 번호 순서(주파수 위치 1의 시간 1부터)로 연속 블록을 나눈다. 블록 크기는 `칸 수 ÷ 그룹 수`이고 나머지는 앞 그룹부터 한 칸씩 더한다. 화면에서는 맨 아래 줄 왼쪽부터 채워진다.
- 단말 수 비례 배정(1.5.0.0): 그룹 g의 칸 수를 `floor(칸 수 × 그룹 단말 수 ÷ 단말 합계)`로 정하고, 남는 칸은 나머지가 큰 그룹부터(같으면 앞 그룹) 한 칸씩 준다. 단말이 있는데 0칸이 된 그룹은 가장 큰 그룹에서 한 칸을 받는다. 단말 0대 그룹은 칸을 받지 않는다. 블록은 그룹 순서대로 연속으로 채운다. 단말 수가 모두 같으면 균등 배정과 같은 배치다. 균등과 마찬가지로 자동 모드라 단말 수·채널 수가 바뀌면 다시 나눈다. 같은 시드 500~2,000회 평균에서 그룹 1만 50대(나머지 27~28대)일 때 Alert 실패가 균등 72.1대 → 비례 61.5대(그룹 미적용 이론 60.9대)로 줄었다.
- 슬롯 배정 방식은 `SlotMode`(균등·단말 수 비례·직접 지정)로 보관하고 실행 배정표에도 남긴다. 화면과 Excel `그룹 설정` 시트에 `균등 / 단말 수 비례 / 직접 지정`으로 표시한다.
- `전체 배정 해제`는 편집 중인 채널 타입의 모든 칸을 미배정으로 만들고 슬롯을 직접 지정 상태로 바꾼다. 처음부터 직접 나눌 때 쓴다.
- 자동인 값은 단말 수·채널 수·심볼레이트·Wave ID·그룹 수가 바뀌면 그에 맞춰 다시 배분한다.
- 직접 지정한 값은 파라미터가 바뀌어도 자동으로 고치지 않는다. 다음 경우 실행 전에 위치와 함께 오류를 알린다.
  - 그룹별 단말 수 합계가 단말 수와 다름(직접 그룹 합계가 단말 수보다 많거나, 모든 그룹이 직접인데 합계가 다를 때)
  - 단말이 있는 그룹에 배정 칸이 없음
  - 시간 슬롯 수나 채널 수가 줄어 범위를 벗어난 배정 칸
  - 그룹 수가 줄어 없어진 그룹의 배정 칸
- 범위를 벗어난 칸과 없어진 그룹의 칸은 사용자가 설정 창에서 해제를 확인해야 지운다.
- 채널 수가 0인 영역은 기존처럼 경쟁하지 않으며 그룹 검사에서 제외한다.

### 경쟁 처리

단말 1번부터 N번까지 순서대로 자기 그룹의 허용 칸 수로 `SelectSlot`을 한 번씩 호출하고, 뽑힌 순번을 허용 칸 목록(오름차순)에서 실제 칸으로 바꾼다. 그룹이 하나이고 모든 칸이 배정되면 허용 목록이 0부터 칸 수−1까지와 같으므로 고정 시드 결과가 기존과 같다. LB는 Alert가 사용한 난수 상태를 이어받으므로 단말 순서를 바꾸지 않는다.

그룹 간 칸이 겹치지 않으므로 한 칸의 충돌은 항상 한 그룹 안에서 생긴다. 그룹별 성공·충돌 칸·충돌 전송 합계는 영역 값과 같고, `그룹별 유휴 칸 합계 + 미배정 칸 수 = 영역 유휴 칸 수`가 성립한다. 그룹별 접속 실패 단말은 종료 시점까지 그 영역에서 한 번도 성공하지 못한 단말을 소속 그룹별로 센다.

그룹 미적용 비교 결과는 같은 시드와 같은 파라미터로 그룹 없이 계산한 기존 방식의 결과다. 따라서 두 결과의 차이는 그룹 배정만의 효과다.

### 시뮬레이션 탭

입력 칸에 `그룹 수`를 추가한다. 그 아래에 `그룹 설정` 버튼과 영역별 요약(배정·미배정 칸, 균등/직접 지정 상태, 오류)을 둔다. 미리보기 격자는 그룹을 쓰면 그룹 색으로 칸을 표시한다. 그룹 검사 오류가 있으면 실행을 막고 오류 위치를 안내한다.

### 그룹 설정 창

- 맨 위에 `채널 타입`(Alert/LB) 선택과 `사용 방법` 버튼을 둔다. 사용 방법은 아래 ①~④ 순서를 안내한다.
- `그룹 설정 결과` 표에 두 채널 타입을 한 줄씩 표시한다: 단말 수(그룹 합계/전체), 단말 배정(자동 균등·직접 n개·자동 m개), 배정 칸/전체 칸, 미배정 칸, 슬롯 배정 방식, 검사 결과(통과는 초록, 문제는 빨강). 행을 클릭해도 채널 타입이 바뀐다.
- ① 그룹 선택: 그룹 표(그룹, 단말 수, 지정(직접/자동), 단말 ID, 배정 칸 수)에서 그룹을 고른다.
- ② 단말 수: 입력한 그룹을 그 값으로 고정하고, 나머지 자동 그룹이 남은 단말을 나눈다. 단말 ID는 그룹 순서대로 다시 연속 배정한다. 빈 값은 자동으로 되돌린다.
- ③ 슬롯 배정: 슬롯 격자는 Alert 위·LB 아래 배치와 축 표기를 유지하며 편집 중인 채널 타입만 활성화한다.
  - 미배정 칸이나 범위를 클릭·드래그하면 선택 그룹에 배정한다.
  - 선택 그룹의 칸에서 시작하면 그 그룹의 칸을 해제한다.
  - 다른 그룹의 칸은 건너뛰고 건너뛴 칸 수를 알린다.
  - 시간·주파수 위치 범위를 입력해 배정하거나 해제할 수 있다.
  - `슬롯 균등 배정`, `전체 배정 해제`(확인 후), 조건부 `범위 밖·없어진 칸 해제` 버튼을 둔다.
- ④ 검사 결과가 통과이면 `적용`으로 반영한다. `취소`는 편집 전 상태를 유지한다.

### 결과 화면

- 설정 값 카드에 그룹 수와 채널 타입별 단말 배정·슬롯 배정 방식을 표시한다.
- 최종 접속 실패 단말 갯수 표는 열을 `채널 타입 | 그룹 적용 | 그룹 미적용`으로 바꿔 같은 시드의 미적용 값을 함께 보인다. 그룹을 쓰지 않은 실행은 `채널 타입 | 단말 갯수`다. 머리글과 채널 타입 열은 가운데, 단말 갯수는 오른쪽 정렬이다. 그룹 통계 표는 11열이 1080px 폭에 들어가도록 15px 글꼴을 쓰고, 머리글과 셀 글자가 잘리지 않게 열 너비를 맞춘다(넘치면 가로 스크롤).
- 그룹을 쓴 실행에서는 도구 모음에 그룹 선택과 `그룹 배정` 보기 전환을 추가한다.
  - 그룹 배정 보기는 그룹 색, 전송 결과 보기는 성공·충돌·유휴 색을 쓴다.
  - 그룹을 선택하면 격자에서 그 그룹의 칸을 강조한다.
  - 전송 추이는 채널 타입 전체, 그룹 하나, 그룹별 작은 그래프 비교 중 하나를 표시한다.
- 하단 표는 `채널 타입 통계`(기존 표), `그룹 통계`, `미적용 비교` 중에서 고른다. 1.3.0.0부터 화면과 Excel의 표 머리글과 안내 문구는 Alert·LB를 "채널 타입"으로 표시한다(이 문서의 "영역"과 같은 뜻).
  - 그룹 통계: 채널 타입, 그룹, 단말 수, 배정 칸 수, 선택 회차의 성공·충돌 전송·충돌 칸·유휴 칸, 선택 회차까지의 누적 성공·누적 충돌 전송, 최종 접속 실패 단말 갯수. 영역마다 마지막에 그룹들의 합을 담은 `합계` 행(굵게)이 있다. 미배정 칸은 합계에 넣지 않는다. 합계 행을 클릭하면 채널 타입 전체 보기로 바뀐다.
  - 미적용 비교: 행은 누적 성공 건수·누적 충돌 전송 건수(선택 회차까지)·최종 접속 실패 단말 갯수(종료 기준), 열은 Alert·LB의 그룹 적용·미적용·차이다.
- 회차 이동 버튼 줄과 하단 표 사이의 구분선을 끌어 그룹 통계 표 높이를 바꾼다(그래프는 최소 200px 유지). 기본 높이는 그래프·표 영역의 약 42%이며 행이 적으면 모든 행이 보이는 높이까지만 커진다. 열 너비는 머리글·내용 길이에 맞춘다.
- 창 크기: 메인 창은 기본 1160×880을 주 화면 작업 영역 안으로 줄여 가운데에 연다. 최소 크기는 980×560(배율에 비례)이다. 결과 탭은 높이 700 미만이면 내용 페이지를 700으로 두고 세로 스크롤한다(마우스 휠·스크롤 막대). 그룹 설정 창은 최소 940×520이고, 배치에 필요한 높이 760보다 낮으면 세로 스크롤한다.
- 하단 표를 바꾸면 컨트롤을 옮긴 뒤 결과 페이지 전체를 다시 그린다. 이전에는 옮긴 버튼의 픽셀이 제목에 복사되어 남는 경우가 있었다.
- 시뮬레이션 탭의 그룹 요약은 Alert·LB 두 줄로 표시하고, 검사 오류가 있으면 요약을 빨간색으로 바꾼 뒤 첫 오류를 상태 줄에 표시한다.
- 회차를 이동하면 그룹·미적용 누적 값도 선택 회차 기준으로 바뀐다.

### Excel 결과 파일

그룹을 쓰지 않은 실행은 기존 두 시트 구성 그대로다. 그룹을 쓴 실행은 다음 시트를 저장한다.

| 시트 | 내용 |
| --- | --- |
| 결과 | 기존 구성 + 그룹 수, 그룹 적용·미적용·차이 최종 비교표, 영역별 성공·충돌 전송 비교 차트 |
| 그룹 설정 | 영역별 배정 요약, 그룹별 단말 수·단말 ID 범위·배정 칸 수·단말 수 지정(직접/자동), 그룹별 슬롯 배정 구간(주파수 위치, 시간 범위, 슬롯 번호 범위) |
| 그룹별 결과 | 그룹별 최종 누적 값·최종 접속 실패 단말 갯수, 영역별 `합계` 행(그룹들의 합), 그룹별 성공·충돌 전송 차트 |
| 미적용 비교 | 회차별 그룹 적용·미적용 성공·충돌 전송 값과 누적 값 |
| 회차별 데이터 | 기존 Alert·LB 회차별 값과 누적 값 |
| 그룹별 회차 데이터 | 영역→그룹→회차 순서의 회차별 통계와 누적 값. 그룹 단위로 행 제한에 맞춰 여러 시트로 나눈다 |

ZIP 항목 목록은 시트·차트 수에 맞춰 동적으로 만든다. 저장 방식은 무압축 ZIP이라 4GB 미만만 저장할 수 있으므로, 저장 전에 예상 크기를 계산해 한도를 넘으면 저장하지 않고 안내한다.

### 검증

1.2.0.0에서 아래 항목을 임시 검증 프로그램(`build/verify`, 배포 ZIP 제외)으로 확인했다. 그룹 미사용 실행과 그룹 1개·전체 칸 실행의 회차별 결과는 원본 1.1.0.0 코어와 같았다. 그룹 미사용 XLSX는 1.1.0.0 출력과 모든 파트 내용이 같았다.

- 그룹 1개·모든 칸 배정 결과가 그룹 미적용 결과와 고정 시드에서 같음
- 같은 그룹 단말 두 대에 칸 하나면 매 회차 충돌, 다른 그룹·다른 칸이면 그룹 간 충돌 없음
- 그룹·영역 집계 일치와 유휴 칸 관계식, 회차 이동 시 누적 값 일치
- 단말 합계 불일치, 칸 없는 그룹, 범위 밖 칸, 없어진 그룹의 칸 검출
- 단말 0대 그룹, 미배정 칸, 비활성 영역, 단말 0대, 완료 회차 0회, 마지막 불완전 주파수 위치
- Excel 시트·표·차트 숫자와 실제 결과의 일치, 그룹 미사용 실행의 기존 파일 구성 유지

1.3.0.0에서 추가로 확인했다. 기본(모두 자동) 설정의 회차별 결과는 원본 1.1.0.0 코어와 여전히 같다. 그룹 미사용 XLSX는 이름 변경(최종 접속 실패 단말 갯수)과 계열 이름 참조 때문에 1.2.0.0과 내용이 다르다.

- 한 그룹 고정 시 자동 그룹이 나머지를 나눔, 0대 고정, 고정 합계 초과·부족 오류, 자동으로 되돌리기, 전체 배정 해제 후 칸 없는 그룹 오류
- 그룹별 결과 시트의 합계 행 = 그룹 행의 합, 성공·충돌·최종 접속 실패 합계 = 결과 시트의 영역 값
- 모든 차트 계열 이름이 `결과` 시트 셀을 참조하고 캐시 값이 셀 값과 같음
