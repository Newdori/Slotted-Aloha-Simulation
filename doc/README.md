# Slotted Aloha 채널 경쟁 상황 시뮬레이션

Windows x64용 프로그램입니다. `excute/SlottedAlohaSimulation-Windows-x64.zip`을 풀고 `SlottedAlohaSimulation.exe`를 실행합니다. 실행할 PC에는 컴파일러나 Excel을 설치할 필요가 없습니다.

현재 버전은 **1.5.0.0**입니다. 1.2.0.0에서 그룹별 슬롯 배정과 그룹 미적용 비교를 추가했고, 1.3.0.0에서 그룹 설정 창·결과 화면·Excel 파일을 다듬었으며, 1.4.0.0에서 반복 실행 평균을, 1.5.0.0에서 단말 수 비례 슬롯 배정을 추가했습니다. 설계는 [설계 문서](DESIGN.md)에 있습니다. 이 문서가 실행용 ZIP에 들어 있는 경우 설계·소스 문서는 별도 소스 ZIP에 있습니다.

## 실행

1. **시뮬레이션** 탭에서 심볼레이트, Wave ID, Alert 채널 수, LB 채널 수를 설정합니다. 채널 수는 영역의 전체 사용 가능 칸 수입니다.
2. 단말 수, 슈퍼프레임 주기, 시뮬레이션 시간을 설정합니다. 시간 입력 단위는 초이며 소수점 아래 세 자리까지 사용할 수 있습니다.
3. **그룹 수**를 정합니다. 0이면 그룹을 쓰지 않고, 모든 단말이 영역의 모든 칸에서 경쟁하는 기존 방식으로 실행합니다. 1~100을 입력하면 Alert와 LB가 같은 수의 그룹을 갖고, 단말과 슬롯이 그룹별로 균등 배정됩니다. 입력 칸 아래 요약과 미리보기 격자에서 배정 상태를 확인할 수 있습니다.
4. 필요하면 **그룹 설정**에서 배정을 바꿉니다. 바꾸지 않으면 균등 배정으로 실행합니다(설정 방법은 아래 절 참고).
   **반복 횟수**에 2 이상(최대 10,000)을 넣으면 같은 설정을 실행마다 다른 시드로 그 횟수만큼 반복하고 평균·표준편차를 보여 줍니다. 한 번의 실행은 우연에 따라 결과가 크게 흔들리므로(예: 최종 접속 실패 단말 수가 실행마다 ±6대 이상), 그룹 적용 효과를 판단할 때는 수백 번 이상 반복한 평균을 보세요.
5. **시뮬레이션 실행**을 누릅니다. 그룹 배정에 문제가 있으면 실행하지 않고 상태 줄에 오류 위치를 표시합니다. 완료하면 **결과** 탭에서 설정 값, 최종 접속 실패 단말 갯수, 마지막 수신 회차가 열립니다. **이전**, **다음** 또는 **회차 이동**으로 다른 회차를 봅니다.
6. **전송 추이**를 누르고 Alert 또는 LB를 선택합니다. 가로축은 수신 시각(초), 세로축은 단말 수입니다. 성공 전송과 충돌 전송을 각각 선으로 표시하고 모든 표시 지점에 숫자를 붙입니다. 회차가 많으면 화면 폭에 맞는 연속 회차 구간을 보여 줍니다. 회차를 이동하면 그래프 범위와 하단 통계가 함께 바뀝니다.
7. **결과 파일 생성**을 누르고 저장 위치를 고릅니다. 표의 테두리와 그래프가 포함된 **Excel 통합 문서(.xlsx)** 한 파일을 생성합니다. 저장 완료 시 `[파일 이름] 파일 생성 완료` 알림창이 뜹니다.

슈퍼프레임 주기는 모든 단말의 접속 간격입니다. 주기가 1초이고 시뮬레이션 시간이 5초라면 1, 2, 3, 4, 5초에 수신 결과를 집계합니다. 한 영역의 채널 수가 0이면 해당 영역에 경쟁 칸이 없습니다. 슬롯 격자에서 각 영역의 맨 아래 줄이 주파수 1(가장 낮은 주파수)이고, 왼쪽 끝이 시간 1입니다. 축 옆의 숫자가 주파수 위치입니다.

하단 표의 **성공 건수**, **충돌 칸 수**, **유휴 칸 수**는 선택한 회차의 값입니다. 충돌 칸 수는 두 건 이상의 시도가 겹친 칸의 수입니다. 충돌 전송 건수는 그런 칸에서 실패한 전송의 수입니다.

**누적 성공 건수**와 **누적 충돌 전송 건수**는 모두 1회차부터 선택한 회차까지 더한 값입니다. 회차를 앞뒤로 이동하면 해당 회차까지의 누적 값으로 바뀝니다. 같은 단말이 여러 번 전송하면 각각의 전송을 셉니다.

**최종 접속 실패 단말 갯수**는 시뮬레이션 종료 시점까지 해당 영역에서 한 번도 성공하지 못한 단말 수입니다. Alert와 LB를 각각 집계하며, 완료된 회차가 없거나 채널 수가 0인 영역은 0으로 표시합니다. 이 값은 종료 시점의 결과이므로 회차를 이동해도 유지됩니다. 입력을 편집하는 동안 **결과** 탭에서 직전 실행을 확인할 수 있습니다.

**반복 실행**을 한 경우 최종 접속 실패 단말 갯수 표는 `평균 ± 표준편차`로 표시되고, 하단 표는 **반복 통계**(평균·표준편차·최소·최대, 그룹을 쓴 실행이면 그룹 적용·미적용·차이)가 먼저 열립니다. 슬롯 격자, 전송 추이, 회차 이동, 나머지 하단 표는 1번째 실행의 결과입니다. Excel 파일에는 **반복 실행** 시트가 추가되어 통계와 반복별 결과가 저장됩니다.

## 그룹별 슬롯 배정

설계 대화에서 말한 ‘영역’은 화면에서 ‘그룹’으로 표시합니다. 기존의 ‘영역’ 표기(Alert·LB)와 헷갈리지 않게 하기 위해서입니다.

- **단말 배정:** 그룹 순서대로 그룹별 단말 수만큼 연속 ID를 배정합니다. 단말 100대에 그룹 1이 10대이면 그룹 1은 단말 1~10번입니다. 단말 수가 0인 그룹에는 어떤 단말도 접속하지 않습니다.
- **영역별 독립 편성:** Alert와 LB의 그룹별 단말 수는 따로 정할 수 있습니다. 같은 단말이 Alert에서는 그룹 1, LB에서는 그룹 2에 속할 수 있습니다.
- **칸 배정:** 한 칸은 같은 영역의 한 그룹에만 배정됩니다. 각 단말은 자기 그룹에 배정된 칸 중 하나를 같은 확률로 고르므로 그룹 사이에는 충돌이 없습니다. 미배정 칸에는 아무도 전송하지 않아 항상 유휴입니다.

### 그룹 설정 방법

**그룹 설정** 버튼은 그룹 수가 1 이상일 때 열립니다. 창 오른쪽 위 **사용 방법** 버튼에도 같은 순서가 있습니다.

0. **채널 타입**에서 Alert 또는 LB를 고릅니다. 두 채널 타입은 따로 설정합니다. 바로 아래 **그룹 설정 결과** 표에서 두 채널 타입의 단말 합계, 배정 칸, 미배정 칸, 검사 결과를 한눈에 봅니다(행을 클릭해도 채널 타입이 바뀝니다).
1. **① 그룹 선택**: 왼쪽 표에서 바꿀 그룹을 클릭합니다. 표의 **지정** 열은 단말 수가 직접 정한 값인지(직접), 자동으로 나눈 값인지(자동) 보여 줍니다.
2. **② 단말 수**: 숫자를 입력하고 **단말 수 변경**(또는 Enter)을 누릅니다.
   - 바꾼 그룹만 그 값으로 고정되고, 나머지 자동 그룹이 남은 단말을 나눠 갖습니다. 예: 단말 300대·그룹 10개에서 그룹 1을 50대로 바꾸면 그룹 2~10이 250대를 28·28…27대로 나눕니다. 그래서 특정 그룹만 바꿔도 합계 오류가 나지 않습니다.
   - 값을 지우고 **단말 수 변경**을 누르면 그 그룹은 자동으로 돌아갑니다. **단말 균등 분배**는 모든 그룹을 자동으로 되돌립니다.
   - 단말 ID는 그룹 순서대로 다시 연속 배정됩니다.
3. **③ 슬롯 배정**: 아래 격자에서 편집합니다.
   - 칸을 클릭하거나 드래그하면 선택 그룹에 배정합니다.
   - 선택 그룹의 칸에서 드래그를 시작하면 그 범위를 해제합니다.
   - 다른 그룹의 칸은 건너뜁니다. 먼저 그 그룹에서 해제해야 가져올 수 있습니다.
   - 처음부터 직접 나누려면 **전체 배정 해제**(확인 후 모든 칸을 미배정으로)를 누른 뒤 그룹을 하나씩 선택해 배정합니다.
   - 시간·주파수 위치(1부터)를 입력해 **선택 그룹에 배정** / **선택 그룹 배정 해제**를 할 수도 있습니다.
   - **슬롯 균등 배정**은 칸을 그룹 순서대로 똑같이 다시 나눕니다(맨 아래 줄 왼쪽부터).
   - **단말 수 비례 배정**은 칸을 그룹별 단말 수 비율대로 나눕니다. 예: 단말 300대·144칸에서 그룹 1이 50대이면 그룹 1은 24칸, 28대 그룹은 13~14칸을 받습니다. 그룹마다 칸당 단말 수가 같아지므로, 그룹별 단말 수를 다르게 정했을 때 실패가 늘어나는 것을 막습니다. 단말 수가 모두 같으면 균등 배정과 결과가 같고, 단말 수를 바꾸면 자동으로 다시 나눕니다. 단말이 있는 그룹은 최소 1칸을 받고, 단말이 0대인 그룹은 칸을 받지 않습니다.
4. **④ 적용**: 아래 검사 결과가 초록색 **검사 통과**이면 **적용**을 누릅니다. **취소**는 편집 전 상태를 유지합니다.

자동인 값은 단말 수·채널 수·심볼레이트·Wave ID·그룹 수가 바뀌면 자동으로 다시 배분됩니다. 직접 지정한 값은 자동으로 고치지 않습니다. 다음과 같은 경우 실행 전에 오류로 알립니다.
- 단말 수 합계가 맞지 않음(직접 지정한 합계가 단말 수보다 많거나, 모든 그룹을 직접 지정했는데 합계가 다름)
- 단말이 있는 그룹에 칸이 없음
- 격자가 줄어 범위를 벗어난 칸
- 그룹 수가 줄어 없어진 그룹의 칸

범위를 벗어난 칸은 그룹 설정 창에서 해제를 확인한 뒤 지워집니다.

**결과 탭(그룹을 쓴 실행):**

- 위쪽 **설정 값**에는 공통 설정과 채널 타입별 채널 수·주파수 위치 수·단말 배정·슬롯 배정 방식이 표시됩니다.
- 오른쪽 **최종 접속 실패 단말 갯수** 표는 채널 타입(Alert·LB)별로 **그룹 적용**과 **그룹 미적용**(같은 시드로 그룹 없이 계산한 값)을 나란히 보여 줍니다. 그룹을 쓰지 않은 실행에서는 **단말 갯수** 한 열만 있습니다.
- **그룹 선택**(채널 타입 전체 / 그룹 1… / 그룹별 비교)과 **그룹 배정 보기 / 전송 결과 보기** 전환을 사용할 수 있습니다.
  - 그룹을 고르면 격자에서 그 그룹의 칸이 강조됩니다.
  - 전송 추이는 그 그룹의 성공·충돌 전송을 표시합니다.
  - 그룹별 비교는 그룹마다 작은 그래프를 보여 줍니다.
- 하단 표는 **채널 타입 통계**, **그룹 통계**, **미적용 비교** 중에서 고릅니다. 표의 첫 열 이름은 **채널 타입**(Alert·LB)입니다.
  - **그룹 통계**에는 그룹별 단말 수(ID), 배정 칸, 선택 회차 값, 선택 회차까지의 누적 값, 최종 접속 실패 단말 갯수가 있습니다. 채널 타입마다 마지막 줄의 굵은 **합계** 행이 그룹들의 합입니다(미배정 칸은 넣지 않음). 합계 행을 클릭하면 채널 타입 전체 보기로 바뀝니다.
  - **미적용 비교**는 같은 시드로 그룹 없이 계산한 결과와 누적 성공·누적 충돌 전송·최종 접속 실패 단말 갯수를 비교합니다.
- 그룹 통계 표가 길면 **회차 이동 줄과 표 사이의 구분선**(가운데 두 줄 표시)을 위로 끌어 표를 키웁니다. 처음에는 그래프·표 영역의 약 42% 높이로 열리고, 창을 세로로 키우면 더 많은 행이 보입니다.
## Excel 결과 파일

**결과** 시트에는 다음이 들어 있습니다.
- 위쪽: 공통 설정과 최종 접속 실패 단말 갯수 표
- 중간: Alert·LB 꺾은선 그래프
- 맨 아래: 두 영역의 최종 누적 결과 표

그래프는 각 지점의 값을 표시하는 Excel 차트이며, 파일 안에서 크기와 표시 범위를 조정할 수 있습니다. 범례에는 계열 이름(성공 건수, 충돌 전송 건수 등)이 표시됩니다. 이름은 결과 시트의 숨긴 Z열에 있습니다. **회차별 데이터** 시트에는 모든 회차의 성공·충돌 전송·충돌 칸·유휴 칸과 해당 회차까지의 누적 전송 건수를 기록합니다. 저장 결과는 화면에서 선택한 회차와 관계없이 실행의 모든 회차를 포함합니다.

그룹을 쓰지 않은 실행은 위 두 시트만 저장합니다(1.1.0.0과 같은 시트 구성). 그룹을 쓴 실행은 다음을 더 저장합니다.

| 시트 | 내용 |
| --- | --- |
| 결과 | 그룹 수, 그룹 적용·미적용·차이 최종 비교표, 영역별 성공·충돌 전송 비교 차트 |
| 그룹 설정 | 영역별 배정 요약, 그룹별 단말 수·단말 ID 범위·배정 칸 수·단말 수 지정(직접/자동), 그룹별 슬롯 배정 구간(주파수 위치·시간 범위·슬롯 번호) |
| 그룹별 결과 | 그룹별 최종 누적 값·최종 접속 실패 단말 갯수, 영역별 **합계** 행(그룹들의 합), 그룹별 차트 |
| 미적용 비교 | 회차별 그룹 적용·미적용 성공·충돌 전송 값과 누적 값 |
| 그룹별 회차 데이터 | 영역→그룹→회차 순서의 회차별 통계와 누적 값. 행이 많으면 그룹 단위로 `그룹별 회차 데이터 2`… 시트에 이어집니다 |
| 반복 실행 | 반복 횟수가 2 이상일 때(그룹 사용 여부와 무관). 평균·표준편차·최소·최대 표와 반복별 결과 |

파일 생성에는 Excel 설치가 필요하지 않습니다. 저장에는 두 가지 한도가 있습니다.
- Excel 행 제한으로 최대 1,048,573회차까지 내보낼 수 있습니다.
- 결과 파일은 압축하지 않은 ZIP이라 4GB를 넘을 수 없습니다. 저장 전에 예상 크기를 계산하고, 한도를 넘으면 저장하지 않고 안내합니다.

15자리를 초과하는 정수 집계는 자릿수 손실을 막기 위해 텍스트로 보존합니다.

## 빌드

Windows에서 x64 MinGW-w64의 `gcc.exe`와 `windres.exe`를 PATH에서 사용할 수 있게 설정하고 프로젝트 루트에서 실행합니다. 현재 개발 환경에서는 GCC 15.2.0을 사용하며 빌드 대상은 `x86_64-w64-mingw32`입니다.

```powershell
.\Build.ps1
```

현재 실행 중인 `build/SlottedAlohaSimulation.exe`는 빌드 전에 종료합니다. 실행 파일과 중간 산출물은 `build`, 배포 압축파일은 `excute`에 생성됩니다. 스크립트가 필요한 출력 폴더를 자동으로 만듭니다. 배포 폴더만 변경하려면 `-DistributionDir 'excute\custom'`을 사용할 수 있습니다. 상대 경로는 프로젝트 루트를 기준으로 해석합니다.

## 프로젝트 구조

```text
Slotted-Aloha-Simulation/
├─ Build.ps1                  빌드 및 압축파일 생성 진입점
├─ src/                       C 소스·헤더·Windows 리소스·manifest
├─ doc/                       사용 안내·설계·코딩 규칙·새 세션용 프롬프트
├─ build/                     빌드로 생성한 EXE·오브젝트 파일
└─ excute/                    실행용 ZIP·다른 PC에서 빌드하기 위한 소스 ZIP
```

`excute`는 프로젝트에서 사용하는 배포 폴더 이름입니다.

| 생성 파일 | 용도 |
| --- | --- |
| `build/SlottedAlohaSimulation.exe` | 개발 PC에서 직접 실행 |
| `excute/SlottedAlohaSimulation-Windows-x64.zip` | 다른 Windows x64 PC에서 압축을 풀고 실행. EXE와 이 사용 안내 포함 |
| `excute/SlottedAlohaSimulation-Source.zip` | 다른 PC에서 EXE를 생성. `src`, `doc`, `Build.ps1` 포함 |

다른 PC에서 빌드하려면 **소스 ZIP**을 새 폴더에 풀고, x64 MinGW-w64의 `gcc.exe`와 `windres.exe`를 준비한 뒤 그 폴더의 `Build.ps1`을 실행합니다. 소스 ZIP에는 컴파일러가 포함되지 않습니다. 프로젝트의 빌드에는 Node.js·Python·Office 라이브러리가 필요하지 않습니다.

새 대화에서 개발을 이어갈 때는 [SESSION_PROMPT.md](SESSION_PROMPT.md)의 내용을 첫 프롬프트로 사용합니다. 다른 PC에서는 문서에 적힌 프로젝트 경로를 실제 압축 해제 경로로 바꿉니다. 코딩 규칙은 [CODING_RULES.md](CODING_RULES.md)에 함께 보관했습니다. 원본은 기존 개발 PC의 `C:\Users\NETCUS\Desktop\git\Coding Rules` 폴더에 있습니다.
